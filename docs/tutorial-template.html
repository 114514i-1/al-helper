把常用网页加入书签

把正在阅读的网页保存到浏览器书签中，下次可以直接打开。

入门基础 · 电脑 · 约 3 分钟

开始前的准备

  • 一台 Windows 电脑
  • 使用 Chrome 或 Edge 打开想收藏的网页

打开添加书签窗口

在网页中同时按下 Ctrl 和 D。检查弹窗中的网页名称，改成容易记住的名字。

网页名称出现在书签编辑窗口中。

如果没有弹窗，先点一下网页空白处，再按快捷键。

保存并找到书签

选择保存位置，点击“完成”。打开浏览器菜单，在“书签”或“收藏夹”里找到刚保存的名称。

完成检查

点击刚保存的书签，确认打开的是同一个网页。

可以修改书签的名字吗？

可以。在书签列表里右键点击这条记录，选择编辑，然后修改名称并保存。
